# 0.4.0 — 2026-11-11

## Added

- Add the `federal-reserve-guide` MCP skill resource.
- **`fedreserve_get_series`** can look up each successful series’ release with `include_release`. Failed secondary lookups preserve the series and identify the affected IDs. ([#36](https://github.com/cyanheads/federal-reserve-mcp-server/issues/36))
- **`fedreserve_get_observations`** accepts `sort_order`, `limit`, and `offset` per series, previews the newest fetched rows, and includes transform and native-unit labels. ([#33](https://github.com/cyanheads/federal-reserve-mcp-server/issues/33))

## Changed

- **`fedreserve_search_series`** defaults to 20 results, normalizes frequency and seasonal-adjustment filters, rejects offsets above 4000 before fetching, and explains empty pages and FRED’s search window on both response surfaces. ([#29](https://github.com/cyanheads/federal-reserve-mcp-server/issues/29))
- **Series batches** normalize and deduplicate IDs, defer IDs beyond the 10/50 processing limits by default, and return `deferred_ids`. Set `FRED_CLAMP_LIMITS=false` to reject oversized batches. Observations validate date ranges before fetching and explain when aggregation requires a frequency. ([#31](https://github.com/cyanheads/federal-reserve-mcp-server/issues/31))
- **Category and release series** sort by descending popularity. Leaf categories support `series_limit` and `series_offset` and report `series_count`. ([#34](https://github.com/cyanheads/federal-reserve-mcp-server/issues/34))
- **DataCanvas** defaults to DuckDB for source, npm, and Docker. The MCPB bundle pins `CANVAS_PROVIDER_TYPE=none` and supports observation paging.
- **Dataframe SQL compatibility.** Bare and quoted unqualified `current_schema` columns, `duckdb_tables` reads through aliases, nested columns, CTEs and staged tables, and `sqlite_schema` aliases are rejected. Qualify a `current_schema` column as `c.current_schema` and use explicit aliases for lambda projections, whose generated names change with DuckDB 2. Constant `range()` calls are accepted.

## Fixed

- **FRED errors** preserve safe upstream diagnostics, declared entity errors, retry information, and cancellation. ([#30](https://github.com/cyanheads/federal-reserve-mcp-server/issues/30))
- **Observation batches and release schedules** distinguish all-failed batches and unavailable schedules from successful empty results. Optional lookup failures preserve primary results. ([#32](https://github.com/cyanheads/federal-reserve-mcp-server/issues/32))
- **`fedreserve_dataframe_query`** marks capped results as truncated and omits `totalCount` when the total is unknown. Registered results report DuckDB types and nullability and preserve SQL NULL separately from empty strings and literal `null` text. ([#35](https://github.com/cyanheads/federal-reserve-mcp-server/issues/35))
- **DataCanvas lifecycle** shares one canvas per tenant, clears expired provenance, and drops orphan tables after provenance-write failures. ([#37](https://github.com/cyanheads/federal-reserve-mcp-server/issues/37))
