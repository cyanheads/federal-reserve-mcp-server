# 0.1.1 — 2026-05-21

## Added

- `src/config/server-config.ts` — Zod-validated env config (`FRED_API_KEY`, `FRED_BASE_URL`, `FRED_DATAFRAME_DROP`).
- `src/services/fred/fred-service.ts` — `FredApiService`: fetch wrapper with retry/backoff, 429 rate-limit handling, and parallel multi-series via `Promise.allSettled`.
- `src/services/fred/types.ts` — FRED domain types (raw, domain, and output shapes for series, observations, categories, releases).
- `src/services/canvas-bridge/canvas-bridge.ts` — `CanvasBridgeService`: thin wrapper connecting `FredApiService` to the DataCanvas API.
- `src/services/canvas-bridge/sql-gate-extras.ts` — SQL guard helpers: allowlist-based SELECT-only validation for DataCanvas queries.
- `src/mcp-server/tools/definitions/fred-search-series.tool.ts` — `fred_search_series`: full-text and series-ID search with filter, tag, and pagination support.
- `src/mcp-server/tools/definitions/fred-get-series.tool.ts` — `fred_get_series`: batch metadata fetch for up to 50 series IDs; parallel upstream requests with partial success.
- `src/mcp-server/tools/definitions/fred-get-observations.tool.ts` — `fred_get_observations`: observation fetch for up to 10 series with date-range, unit transform, and frequency options; multi-series or >500-row results spill to DataCanvas.
- `src/mcp-server/tools/definitions/fred-browse-categories.tool.ts` — `fred_browse_categories`: FRED category tree navigation; root or by `category_id`.
- `src/mcp-server/tools/definitions/fred-get-release.tool.ts` — `fred_get_release`: release lookup by ID or name search; returns release metadata and paginated series list.
- `src/mcp-server/tools/definitions/fred-dataframe-describe.tool.ts` — `fred_dataframe_describe`: list active DataCanvas dataframes (canvas IDs, row counts, schemas).
- `src/mcp-server/tools/definitions/fred-dataframe-query.tool.ts` — `fred_dataframe_query`: SELECT queries against registered DataCanvas dataframes.
- `src/mcp-server/tools/definitions/fred-dataframe-drop.tool.ts` — `fred_dataframe_drop`: drop a DataCanvas dataframe by canvas ID; access controlled via `FRED_DATAFRAME_DROP` env var.
- `src/mcp-server/tools/definitions/index.ts` — barrel export for all tool definitions.
- `tests/tools/fred-search-series.tool.test.ts` — unit tests for `fred_search_series`.
- `tests/tools/fred-get-series.tool.test.ts` — unit tests for `fred_get_series`.
- `tests/tools/fred-get-observations.tool.test.ts` — unit tests for `fred_get_observations`.
- `tests/tools/fred-browse-categories.tool.test.ts` — unit tests for `fred_browse_categories`.
- `tests/tools/fred-get-release.tool.test.ts` — unit tests for `fred_get_release`.
- `tests/tools/fred-dataframe-describe.tool.test.ts` — unit tests for `fred_dataframe_describe`.
- `tests/tools/fred-dataframe-query.tool.test.ts` — unit tests for `fred_dataframe_query`.
- `tests/tools/fred-dataframe-drop.tool.test.ts` — unit tests for `fred_dataframe_drop`.
- `tests/services/fred/fred-service.test.ts` — unit tests for `FredApiService`.
- `tests/services/canvas-bridge/sql-gate-extras.test.ts` — unit tests for SQL guard helpers.
