# 0.1.6 — 2026-05-23

## Fixed

- **`fred_get_observations`** — `truncateInline` now distributes preview rows evenly across series instead of top-loading earlier series.
- **`fred_get_series`** — empty array input rejected with `min(1)`.
- **`fred_get_observations`** — `frequency_too_high` correctly classified by inspecting FRED response body; date fields validated with `YYYY-MM-DD` regex.
- **`fred_get_release`** — no-input error uses `ctx.fail()` with a recovery hint instead of a plain thrown error.
- **`fred_get_release` / `fred_browse_categories`** — nonexistent IDs reclassified from generic 400 to `NotFound`.
- **`fred_get_series` / `fred_get_observations`** — empty string series IDs rejected with `min(1)`.
- **`fred_search_series`** — `offset` capped at 4999 to prevent opaque FRED 400 errors.
- **`fred_get_release`** — mutual exclusion enforced for `release_id` + `release_search`; previously accepted both silently.
