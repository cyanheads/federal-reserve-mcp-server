# 0.2.3 — 2026-08-21

## Added

- **Enrichment totals** — `fedreserve_search_series`, `fedreserve_get_release`, and `fedreserve_dataframe_query` emit `totalCount` via `ctx.enrich.total()`, so clients see the pre-pagination result count in both `structuredContent` and `content[]`.

## Changed

- **Framework** `@cyanheads/mcp-ts-core` `^0.10.9` → `^0.12.3` — adopts the MCP SDK v2 protocol era: HTTP endpoints serve revision 2026-07-28 alongside the 2025 era, tool inputs validate strictly, and multi-round-trip `ctx.requestInput` replaces `ctx.elicit`.
- **`fetchWithTimeout`** deadlines bound the whole exchange including the response body, and `withRetry` honors `Retry-After` headers.
- **Definition linter** reports unsatisfiable emitted schemas and format-parity gaps it previously passed over.
- **Telemetry** records output-schema, `format()`, and enrichment failures as failed calls rather than successful ones.
- **Upstream FRED calls** route through `fetchWithTimeout` with a 15s bound and `expectedStatuses: [400, 404]`, replacing raw `fetch` + `httpErrorFromResponse`.
- **TypeScript** `^6` → `^7`; non-null assertions in multi-series handlers replaced with explicit positional-mismatch guards; base tsconfig typechecks `tests/` while the build config restores emit.
- **Docker image** moves to Bun 1.4.0 with a host-arch build stage (`--platform=$BUILDPLATFORM`), cache-mounted installs, and `--omit=peer` production dependencies.
- **Supply-chain guard**: `bunfig.toml` holds freshly published versions for 3 days (`minimumReleaseAge`) and runs the Socket install scanner; the first-party framework is exempt from the hold.
