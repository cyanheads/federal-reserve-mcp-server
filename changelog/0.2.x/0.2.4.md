# 0.2.4 — 2026-09-20

## Added

- **`inputAliases`** on `fedreserve_get_series`, `fedreserve_get_observations`, and `fedreserve_search_series` — accepts FRED's own parameter spellings (`series_id`, `search_text`) alongside the declared names; `inputSchema` is unchanged.
- **Claude Code and Codex plugin manifests** (`.claude-plugin/`, `.codex-plugin/`) and the shared `codeql.yml` workflow.

## Changed

- **Framework** `@cyanheads/mcp-ts-core` `^0.12.3` → `^0.13.6`. Bun engines floor rises to `>=1.4.0`. A rejected tool call now classifies as `InvalidParams` (`-32602`) instead of `ValidationError` (`-32007`), and `content[0].text` closes with a `Recovery: <hint>` line and a `(reason invalid_arguments)` suffix. The advertised tool surface (`inputSchema`, `outputSchema`, descriptions, annotations) is unchanged.
- **`MCP_SESSION_MODE` defaults to `stateless`** across `.env.example`, the Dockerfile, and `src/index.ts` ([#23](https://github.com/cyanheads/federal-reserve-mcp-server/issues/23)) — previously the container ran stateless while a source or npm run fell through the framework schema's `auto` default to `stateful`. No tool here holds per-session state.

## Security

- **`fedreserve_dataframe_query`'s Markdown table formatter escapes backslashes before pipes** ([#24](https://github.com/cyanheads/federal-reserve-mcp-server/issues/24)) — a cell's own backslash was consumed as the leading character of the pipe escape, silently dropping characters from `content[]`. `structuredContent` was unaffected. Resolves CodeQL alert #1 (`js/incomplete-sanitization`).
