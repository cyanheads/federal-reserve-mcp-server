# 0.2.0 — 2026-05-24

## Changed

- **Repository** renamed from `fred-mcp-server` to `federal-reserve-mcp-server`.
- **npm package** renamed from `@cyanheads/fred-mcp-server` to `@cyanheads/federal-reserve-mcp-server`; old package deprecated on npm ([#16](https://github.com/cyanheads/federal-reserve-mcp-server/issues/16)).
- **Tool prefix** changed from `fred_` to `fedreserve_` across all 8 tools: `fedreserve_search_series`, `fedreserve_get_series`, `fedreserve_get_observations`, `fedreserve_browse_categories`, `fedreserve_get_release`, `fedreserve_dataframe_describe`, `fedreserve_dataframe_query`, `fedreserve_dataframe_drop`.
- **Docker image** renamed to `ghcr.io/cyanheads/federal-reserve-mcp-server`.
