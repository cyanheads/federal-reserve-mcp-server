# 0.2.1 — 2026-06-12

## Changed

- **Framework** `@cyanheads/mcp-ts-core` `^0.9.6` → `^0.10.6`.
- **System-catalog SQL gate** now delegates to the framework's `assertNoSystemCatalogs` (`@cyanheads/mcp-ts-core/canvas`); the local `sql-gate-extras.ts` implementation is removed. Double-quoted catalog names are now treated as quoted identifiers and rejected (previously stripped as string literals).
- **`createApp()`** sets `name` and `title` explicitly to `federal-reserve-mcp-server` so the display identity is the hyphenated repo name on every client surface.
- **`FRED_DATAFRAME_DROP_ENABLED`** parsing switched from `z.coerce.boolean()` to `z.stringbool()` — only recognized truthy/falsy strings flip the flag, so a stray non-empty value no longer reads as `true`.
- **`deriveAllNullableSchema`** dropped its manual `nullable: true` remap; framework `inferSchemaFromRows` always emits nullable columns as of mcp-ts-core 0.10.4.

## Removed

- **`src/services/canvas-bridge/sql-gate-extras.ts`** — superseded by the framework's `assertNoSystemCatalogs`.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.9.6` → `^0.10.6`
- `@biomejs/biome` `^2.4.15` → `^2.5.0`
- `@types/node` `^25.9.1` → `^25.9.3`
