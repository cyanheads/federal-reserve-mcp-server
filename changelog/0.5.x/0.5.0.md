# 0.5.0 — 2026-11-20

## Added

- Added `fedreserve_list_release_dates` to page scheduled FRED releases across an inclusive date window. ([#44](https://github.com/cyanheads/federal-reserve-mcp-server/issues/44))

## Changed

- **`fedreserve_get_series`** returns notes on request. Pass `include_notes: true` to retain methodology, attribution, and licensing text in the response. ([#42](https://github.com/cyanheads/federal-reserve-mcp-server/issues/42))
- **`fedreserve_search_series`** accepts FRED frequency and seasonal adjustment short codes and reports `invalid_tag` for an unknown tag. Discover tag names with `fedreserve_get_series` and `include_tags: true`. ([#41](https://github.com/cyanheads/federal-reserve-mcp-server/issues/41))
- **`fedreserve_get_observations`** reports seasonal adjustment when available and warns when `sum` adds annualized values during downsampling. Use `avg` to retain their rate basis. ([#43](https://github.com/cyanheads/federal-reserve-mcp-server/issues/43))

## Removed

- **`fedreserve_get_release`** removes `search_alternatives` from its success schema. Read matching release IDs from the ambiguity error. ([#45](https://github.com/cyanheads/federal-reserve-mcp-server/issues/45))

## Fixed

- **`fedreserve_get_observations`** returns complete inline pages (20 rows per series by default) with a continuation offset for each series that has remaining rows. ([#39](https://github.com/cyanheads/federal-reserve-mcp-server/issues/39))
- **`fedreserve_browse_categories`** pages directly attached series on categories with subcategories as well as on leaf categories. ([#40](https://github.com/cyanheads/federal-reserve-mcp-server/issues/40))
- **Release and dataframe recovery** points callers to series-to-release lookup, identifies missing named dataframes, and reports how to resolve a `register_as` name clash. ([#45](https://github.com/cyanheads/federal-reserve-mcp-server/issues/45))
